\doxysubsection{Detailed Description}
Represents an administrative user with elevated privileges in a chat room. 

A specialized \doxylink{class_user}{User} with administrative privileges in a chat room.

Inherits from the base \doxylink{class_user}{User} class and overrides messaging behavior to include administrative tags. \doxylink{class_admin_user}{Admin\+User} can send and receive messages with special formatting.
