This project implements a chat mediator system using the Mediator design pattern. The system allows users to communicate through a chat room, with commands to send and save messages. It also includes iterators for users and messages, and an observer for notifications.\hypertarget{md__r_e_a_d_m_e_autotoc_md1}{}\doxysection{\texorpdfstring{Components}{Components}}\label{md__r_e_a_d_m_e_autotoc_md1}

\begin{DoxyItemize}
\item {\bfseries{\doxylink{class_chat_room}{Chat\+Room}}}\+: Abstract mediator interface for managing communication between users.
\item {\bfseries{\doxylink{class_ctrl_cat}{Ctrl\+Cat}}}\+: Concrete mediator managing user interactions in the chat room.
\item {\bfseries{\doxylink{class_dogorithm}{Dogorithm}}}\+: Another concrete mediator facilitating communication between users.
\item {\bfseries{\doxylink{classsend_message_command}{send\+Message\+Command}}}\+: \doxylink{class_command}{Command} for sending messages.
\item {\bfseries{\doxylink{class_save_message_command}{Save\+Message\+Command}}}\+: \doxylink{class_command}{Command} for saving messages.
\item {\bfseries{Normal\+User}}\+: Invoker for commands.
\item {\bfseries{\doxylink{class_user_iterator}{User\+Iterator}}}\+: Iterator for iterating over users.
\item {\bfseries{\doxylink{class_message_iterator}{Message\+Iterator}}}\+: Iterator for iterating over messages.
\item {\bfseries{Notification\+Service}}\+: \doxylink{class_observer}{Observer} for receiving notifications from the \doxylink{class_chat_room}{Chat\+Room}.
\end{DoxyItemize}\hypertarget{md__r_e_a_d_m_e_autotoc_md2}{}\doxysection{\texorpdfstring{Build Instructions}{Build Instructions}}\label{md__r_e_a_d_m_e_autotoc_md2}
