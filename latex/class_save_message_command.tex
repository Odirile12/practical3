\doxysubsection{Detailed Description}
A concrete \doxylink{class_command}{Command} that saves a message to a chat room\textquotesingle{}s history. 

Implements the \doxylink{class_command}{Command} interface to encapsulate the action of persisting a message sent by a user into the chat room\textquotesingle{}s message log.
