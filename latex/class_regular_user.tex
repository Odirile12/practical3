\doxysubsection{Detailed Description}
A basic implementation of the \doxylink{class_user}{User} class representing a standard chat participant. 

\doxylink{class_regular_user}{Regular\+User} interacts with chat rooms by sending and receiving messages directly, without command queuing or advanced features. Includes a placeholder status field.
