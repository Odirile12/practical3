\doxysubsection{Detailed Description}
Concrete command for sending messages in the chat system. 

Implements the \doxylink{class_command}{Command} interface and encapsulates the action of sending a message from a user to a chat room. This promotes decoupling and supports extensibility via the \doxylink{class_command}{Command} design pattern.

Delegates the message dispatch to the \doxylink{class_chat_room}{Chat\+Room}\textquotesingle{}s send\+Message method.

Performs a safety check to ensure both the room and user are valid. Then delegates the message dispatch to the \doxylink{class_chat_room}{Chat\+Room}\textquotesingle{}s send\+Message method. This encapsulates the sending logic using the \doxylink{class_command}{Command} design pattern.
